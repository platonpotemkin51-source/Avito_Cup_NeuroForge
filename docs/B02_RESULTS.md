# B02 — усреднённая история: итог двух seed

**Решение: B02 проверена на двух seed. Текущий вариант закрыт без принятия как подтверждённого улучшения.** Полезность явной истории вообще не опровергнута; проверено простое усреднение нормализованных векторов вместе с флагом отсутствия пригодной истории.

## Что проверили

| Задача | Зачем | Гипотеза | Результат |
|---|---|---|---|
| Контроль и история, seed=42 | Измерить эффект истории | B02 | Пять эпох каждого варианта; +0.00136577 |
| Повтор пары с seed=123 | Проверить устойчивость | B02 | Пять эпох каждого варианта; +0.00000535, практически ничья |
| Аудит условий | Исключить посторонние изменения | B02 | Исходники и выбранные файлы одинаковы; конфиги отличаются только seed/variant |
| Проверка прогнозов | Проверить метрику и покрытие | B02 | Все четыре набора покрывают полную val, ключи уникальны, scores конечны; NDCG пересчитана |
| Парный bootstrap по пользователям | Оценить разброс результата на val | B02 | Для seed=123 интервал включает ноль |

## Условия

50 000 train-лент, вся val (14 423 ленты / 1 389 971 кандидат), пять эпох, CPU, batch=2, 4 потока. Обе версии имеют 93 097 параметров. Одинаковые AdamW/BCE, данные и правило выбора checkpoint по максимальной полной NDCG. Контроль обнуляет исторический вектор и флаг, история передаёт реальные значения. Источники baseline/ и общая метрика не менялись.

## Результаты на полной val

| Seed | Эпоха контроля | Эпоха истории | NDCG контроля | NDCG истории | Разница | 95% интервал |
|---|---|---|---|---|---|---|
| 42 | 5 | 5 | 0.33372076 | 0.33508653 | +0.00136577 | [+0.00019725; +0.00254205] |
| 123 | 4 | 4 | 0.33378451 | 0.33378985 | +0.00000535 | [-0.00132875; +0.00131651] |

Интервалы: 2000 парных bootstrap-повторов по user_id, seed=2026. Они отражают неопределённость на этой val для фиксированных моделей, не учитывают все возможные seed и выбор эпохи на той же выборке. Независимой финальной оценки нет.

## Вывод

На первом seed был небольшой положительный сигнал. Во втором разница составляет около пяти миллионных NDCG: практически равенство. Совпадения знака недостаточно — величина эффекта не воспроизвелась, интервал второго seed допускает как небольшой плюс, так и минус. Усреднение не принимаем как надёжное улучшение; третье такое же обучение сейчас не запускаем.

На длинной истории (33–256 событий) seed=123 дал -0.00004624, на короткой +0.00034153, на пустой +0.00204413. Малый срез пустой истории (194 ленты) нельзя трактовать как пользу самих событий: влияют флаг и общие выученные веса. Польза среднего отдельно от флага здесь не изолирована.

## Проверки, исходники и артефакты

- 20 тестов прошли: метрики, masks/padding, история, перестановки, градиенты, сохранение весов, правильные пары, отказ при разных seed или неполном обучении.
- scripts/compare_b02.py выполняет воспроизводимый аудит пары: конфиги, версии среды, source hashes, состав файлов, завершение эпох, выбор checkpoint, ключи/конечность scores и пересчёт NDCG.
- experiments/B02/results.json: все результаты двух пар и вывод.
- experiments/B02/comparison.csv: компактная таблица; seed123.json: детали повтора; night_seed42.json: исходный ночной результат.
- runs/B02-control-50k-seed42-01/ и runs/B02-history-50k-seed42-01/: исходная пара.
- runs/B02-control-50k-seed123-01/ и runs/B02-history-50k-seed123-01/: повтор. В каждой папке веса, прогнозы, history/config/metrics/manifest.json.
- runs/B02-seed42-audit/ и runs/B02-seed123-audit/: парные метрики каждой ленты (локальные Parquet) и JSON-аудит.
- runs/B02-seed123.log: журнал последовательного повтора; runs/B02-review/: сводный отчёт, результаты и снимок исходников.
- Фактический source commit и dirty-state остаются в исходных манифестах; код B02 пока не закоммичен. При аудите все пять source hashes совпадали во всех четырёх запусках и с файлами на момент аудита. Исходники B02 зафиксированы в b9ccf32 и локальном source_snapshot; последующие IO-опции полного запуска описаны в FULL_CPU.md.
- Веса и данные в Git не добавлялись. Ансамбль и сервис не проверялись.

## Воспроизведение повтора

Использовать новые выходные папки. Запускать обучения последовательно.

```bash
uv run --project baseline python scripts/train_b02.py --config configs/B02_cpu_50k_seed123.json --data data/competition --variant control --allow-large --output runs/B02-control-repeat-seed123
uv run --project baseline python scripts/train_b02.py --config configs/B02_cpu_50k_seed123.json --data data/competition --variant history --allow-large --output runs/B02-history-repeat-seed123
uv run --project baseline python scripts/compare_b02.py --data data/competition --control runs/B02-control-repeat-seed123 --history runs/B02-history-repeat-seed123 --output runs/B02-audit-repeat-seed123
```
