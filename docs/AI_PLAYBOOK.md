# Запуск ИИ по роли

Коллега открывает репозиторий в своём ИИ-инструменте и пишет:

> Я участник 1. Прочитай AGENTS.md и docs/AI_PLAYBOOK.md, проверь состояние репозитория и начни первые незавершённые задачи моей роли. Выполняй работу, сохраняй воспроизводимые результаты. Если датасета нет, готовь код и синтетические проверки без выдуманных метрик.

Другой коллега заменяет номер на 2. Капитан использует 3. Если инструмент не загружает AGENTS.md автоматически, явно открыть его в контексте. Не рассчитывать на память чужого чата.

## Участник 1 / A

Зона владения: `src/neuroforge/features/`, `src/neuroforge/models/tabular/`, конфиги A, тесты признаков. Сначала воспроизведи smoke CatBoost через scripts/run_baseline.py. Затем A01–A03: полный NDCG, агрегаты истории, сходства. Реализуй общий метод получения признаков одной ленты; поддерживай пустую историю, пропуски векторов и неизвестные категории. Добавь тесты реальных рисков. До тяжёлого обучения измерь память. Не меняй baseline/. Передай капитану готовые ключевые прогнозы и конфигурацию.

## Участник 2 / B

Зона владения: `src/neuroforge/models/neural/`, конфиги B, тесты сети. Начни с переноса или адаптации исходной сети вне baseline/ и выбора checkpoint по общему NDCG. Затем B02/B03: агрегированная история и DIN. Ленты полностью сохраняются при батчинге; padding исключён из loss и attention. Проверь пустую историю, missing-векторы и перестановки кандидатов. Точная временная давность событий неизвестна, доступен только их порядок. Не запускай полный RAM-загрузчик на 16 ГБ без профилирования. Дальше B04–B07 согласно результатам.

## Участник 3 / C

Зона владения: `metrics.py`, `cli.py`, протокол, splits, реестр, ансамбли. Сначала проверь окружение и синтетические тесты, уточни расхождение NDCG/@30, зафиксируй temporal split после появления данных. Организуй очередь GPU. Не задерживай A/B ожиданием недоступных метрик: они могут реализовывать код. Затем C01–C07. Поддерживай независимый поздний контроль, принимай прогнозы по ключам, проверяй точное покрытие и прирост ансамбля. Создай manifest артефактов и инструкции воспроизведения финального решения.

## Завершение каждого рабочего цикла

Обновить experiments/registry.csv, сохранить конфиг и отчёт, указать команду воспроизведения. Сообщить: что сделано, какие проверки реально прошли, измерено ли качество, что нужно следующему участнику. Общие файлы изменять согласованно. Нет данных — статус `implemented_unmeasured`; нет окна GPU — готовить следующий код и анализ, не запускать конкурирующее обучение.
