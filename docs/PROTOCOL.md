# Общий протокол v1

Основной результат: полный NDCG, бинарный gain, discount 1/log2(rank+1), одинаковый вес лент. При одинаковых scores негативы раньше позитивов. Для ленты без позитивов NDCG=1. @10/@30 — диагностика. Организаторы должны подтвердить противоречивое упоминание @30 в описании.

Предварительная граница: val 22–23 сентября development, 24 сентября контроль. Не утверждена до аудита объёма. Сначала создать версионированный список feed_id с хешем и заморозить. Не пересматривать границы по результатам модели. Ранние срезы train не эквивалентны randomized val.

Формат прогноза: feed_id int32, item_id int32, score float32. Уникальность пары и полное покрытие reference обязательны. NaN, infinity и null запрещены. Каждый прогон: config.json, manifest.json (commit, seed, данные, признаки, окружение), predictions_val.parquet, metrics.json, report.md. Для финалистов также веса и test-прогнозы. Ключи не заменять порядком строк.

Один ID объявления может иметь разные embedding_idx в разных split. -1 не индексировать. Векторы int8 преобразовывать перед арифметикой. Все массивы кандидатов разворачивать совместно. Историю не путать с кандидатами. Не использовать target, pos и искусственный порядок кандидатов как доступные test-признаки.

Агрегаты меток только по прошлым данным. Обучаемый ансамбль только по отложенным прогнозам. Безметочное использование test/val в обучении — отдельный режим после проверки правил. Неизвестные коды событий не называть конкретными действиями.

Закрытый контроль капитан проверяет на этапах принятия, не после каждого подбора. Маленький прирост перепроверять по seed/времени; доверительные интервалы учитывать повторных пользователей. Public — дополнительная проверка, не замена локальному эксперименту.
